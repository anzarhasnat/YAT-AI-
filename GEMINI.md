# YAT AI Workspace Rules

## Strict Git Policy: Never Push Document Exports, Banners, or PDFs
- **NEVER stage, commit, or push PDF files (`*.pdf`), Word documents (`*.docx`, `*.doc`), presentation banners (`*banner*.png`, `*Banner*.png`), or diagram exports to GitHub under any circumstances.**
- All compiled reports, banners, and presentation artifacts must remain strictly local on the machine.
- Always check `.gitignore` and `git status` before committing to guarantee no document or banner binaries are tracked.
